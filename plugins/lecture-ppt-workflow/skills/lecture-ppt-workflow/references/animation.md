# 动画与备注

动画实际写入PPTX，以教师点击推进，常规出现/淡入/擦除约0.3—0.6秒，不自动翻页、不加音效。材料和问题先显示，点击揭示线索与参考分析。流程按知识逻辑展开，结束后模型完整可读。分成多页不自动等于动画已实现。

新增页面可用工具约定的reveal_组号_对象号命名，每组一次点击、组内同时淡入。工具只处理显式指定的新增页，遇既有timing拒绝覆盖；不能用它重建整份导师动画。继承页保留媒体触发器和备注。名称非法、重复对象ID、父组与子对象同时动画等须报错。

备注帮助讲授：目的、易错点、适用条件、前后衔接、来源；情境补建议用时、提问追问、学生可能回答、参考分析和点击顺序。不写工具与检查日志，不只是复制页面文字。

验收分层：包内目标引用与点击结构；最终静态内容和渲染；真实PowerPoint/WPS放映的初始隐藏、点击揭示与媒体播放。读取COM动画集合不等于看到放映效果，抽查也不能称全软件兼容。缺播放条件时保留正确结构并明确未验证范围。
