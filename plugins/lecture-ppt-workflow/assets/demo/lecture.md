# 第三章 工作分析（示例讲义）

> 本讲义为本项目原创的教学示例，用于演示“讲义 → AI 大纲 → 可编辑课件”的流程。内容参照人力资源管理课程的通用知识编写，不摘录任何教材原文。

## 一、工作分析的含义与作用

工作分析（Job Analysis）是通过系统地收集、整理与工作有关的信息，明确某一岗位的工作内容、职责、工作条件，以及任职者应具备的知识、技能和能力的过程。工作分析的对象是岗位本身，而不是某一位员工；它的直接产出是工作描述与任职资格，通常合称为工作说明书。

工作分析是多项人力资源管理工作的共同基础：招聘甄选需要它明确用人标准，减少凭印象招人；培训开发需要对照任职要求识别能力差距；绩效管理需要清楚的职责作为考核依据；薪酬设计需要它为岗位价值评价提供信息。

## 二、工作分析的流程

工作分析一般分为四个阶段。准备阶段要明确分析目的，确定目标岗位，组建工作小组；调查阶段选择合适的方法，收集岗位职责、任务与工作条件等信息；分析阶段对信息进行整理和核实，归纳岗位要素与任职要求；完成阶段编写工作说明书，并在应用中定期修订。分析目的不同，侧重点也不同：为招聘进行的分析更关注任职资格，为薪酬进行的分析更关注岗位价值。

## 三、工作分析的常用方法

1. 观察法：分析人员直接观察任职者的工作过程。信息直观、真实，但不适合以脑力劳动为主的岗位。
2. 访谈法：与任职者及其主管面谈。可以深入了解职责和工作难点，但耗时较多，也容易受访谈者主观影响。
3. 问卷法：发放结构化问卷收集信息。覆盖面广、便于统计，但对问卷设计要求高，回答可能失真。
4. 工作日志法：任职者按时间顺序记录工作活动。信息详细、连续，但会增加任职者负担，也可能遗漏。

实际操作中通常组合使用多种方法，互相印证。

## 四、工作说明书

工作说明书由两部分组成。工作描述回答“这是什么工作”，包括岗位名称与所属部门、工作职责与主要任务、工作条件与环境、汇报与协作关系；任职资格回答“什么样的人能做好”，包括学历与专业背景、知识与技能要求、相关工作经验、能力与个性特征。简单地说，工作描述针对“事”，任职资格针对“人”。

岗位职责会随业务变化而变化，工作说明书需要定期复核和更新，否则会与实际工作脱节，影响招聘、考核等工作的公正性。
