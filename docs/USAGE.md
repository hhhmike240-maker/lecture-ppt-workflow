# 先读我：教师试用步骤

这是可上传的早期试用版。生成依赖公开npm的PptxGenJS；先读README，不把node_modules或办公软件提交到仓库。

1. 解压完整目录，保留讲义与标准PPT原件；不要只复制SKILL.md。
2. 若环境允许，运行根目录install.py。名称与导师旧版不同，可共存。已有安装会拒绝覆盖。
3. 新建任务，明确调用`$lecture-ppt-workflow`。让模型先确认发现Skill、读取其规范、探测依赖。未发现时报告安装目录及错误，不假装已使用。
4. 上传讲义和有使用权限的标准PPT，说明课时/学生背景、版本与案例授权。未说的内容可做合理教学深度假设，不能擅自引入真实案例。
5. 首稿核对：知识是否上屏、原图有无遗漏、标题/来源是否相撞、章末关系图是否完整；最后自行放映检查动画。
6. 反馈可写：“仅改第2页，保留知识，把材料与讨论分开，小标题靠近横线，来源移到独立区域。输出新文件。”
7. 将长期偏好记录在自己的课程配置，不污染通用Skill。不同章节重复提供内容与标准，避免引用错误旧版。

输出通常是新PPTX、检查/修订说明。过程文件保留以便继续修改；不要只凭build目录名就删除。确定最终PPT能独立打开、原件与需保留素材已备份后，列清单由本人确认清理。

## 常见问题

- 安装Skill后能离线自动写课件吗？不能，它需要模型和工具。
- 只上传Word就能复刻旧模板吗？需提供指定标准或可访问的已核验样式配置。
- 为什么生成失败而检查可用？它们依赖不同，查看doctor结果。
- 需要每次安装吗？同环境安装一次；每次新任务仍应确认Skill被加载。App版本差异尚未全面验证。
- 能删“虚构/来源”来让页面自然吗？不能；缩短、合理摆放，复杂说明进备注。
- 是否承诺导师原来的效果？不能；真实试用经过教师多轮修订，其他课程仍需验收。
