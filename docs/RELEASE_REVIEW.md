# 发布审阅与下一步

## 判断

本目录已经整理为**可上传 GitHub 的源代码早期试用版**，但不是“其他教师下载后无需额外环境即可完成视觉验收”的版本。上传和端到端普遍可用是两个不同判断。仍有两个具体限制：

1. 跨平台静态渲染需要使用者自行安装LibreOffice + Poppler；Windows PowerPoint脚本已做本机导出检查，但未验证动态放映。
2. 中文字体、模板素材和教师讲义的权利与兼容性仍由使用者负责；本项目不分发这些材料。

本版本明确按“工作流、规则、检查脚本和原创演示”发布，不把私有运行时伪装成项目代码，也不声称普通电脑可直接生成。

## 最小方案（已执行）

现有页面规格已接入可通过公开npm获取的PptxGenJS 4.0.1（MIT），并保留解析、内容覆盖、样式检查、动画补丁和静态导出工具。适配范围仅覆盖本项目已支持的文字、形状、表格、图片和连线，不扩展公式、媒体或UI。

已在隔离目录安装锁定依赖，生成standard/before/after三份示例，核验备注、对象映射、动画结构、原生表格、图片比例和关系图，并使用PowerPoint Windows脚本导出静态预览。第二设备、LibreOffice跨平台渲染、实际动态放映和复杂模板仍需后续验证，不能据此宣称所有环境等价。
