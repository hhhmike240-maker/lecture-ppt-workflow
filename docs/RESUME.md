# 简历与面试描述

## 建议简历表述

**教学课件生成与反馈迭代工作流｜需求与验收负责人，AI辅助实现**

面向高校教师课件制作需求，负责需求沟通、教师反馈整理及课件效果验收，将知识覆盖、模板规范、标题间距、图注安全区和授课备注要求整理为可复用Codex Skill；在AI辅助下实现并整合PPT解析、生成适配、动画与检查脚本。支持教师独立制作后续章节并完成多轮反馈修订，准备原创示例、测试记录和公开候选文档；将公开示例适配至PptxGenJS，完成30项基础测试，并明确披露字体、渲染及跨设备验证边界。

## 面试时应说明

- 我的工作：明确真实需求、协调教师意见、决定修改范围、验收知识与视觉效果、将反馈转为规则。
- AI辅助：代码和文档编写、素材组织、部分检查与排版执行。可说明自己阅读、理解和验证了哪些实现，不把全部代码说成独立手写。
- 现有工具：模型负责理解和生成，第三方演示引擎负责PPTX生成/渲染；项目增加可复用规则、适配和检查流程。
- 证据：匿名化的实际试用总结、可查看的原创演示、测试与限制记录。不要展示私人聊天或教师课件，除非另获许可。
- 不写“独立开发大模型”“全自动教学平台”“通用PPT引擎”，不编造用户数、节省比例或商业收益。当前应称公开候选，而非已开源发布。
